# Alise in Tokyo

**Alise in Tokyo** is a cyberpunk-Tokyo inspired social soundboard RPG platform where users collect characters, unlock sound combinations, build personal boards, and participate in a shared evolving story world.

The project began as a personal interactive birthday soundboard and is evolving into a scalable creative platform combining:

- character progression
- sound-mix gameplay
- collectible combo cards
- profile-centric identity building
- social interaction loops
- collaborative storytelling

The long-term vision is a living digital Tokyo night universe built together with its players.

---

# Project Vision

This is **not a soundboard app**.

This is a **profile-centric creative platform** where users:

- grow characters
- unlock sound slots
- collect themed sound combo packs
- earn credits through activity
- interact with friends’ boards
- contribute to shared stories
- build their own identity inside a cyberpunk Tokyo world

The platform blends ideas from:

- rhythm interaction tools
- collectible card systems
- lightweight RPG progression
- social profile platforms
- collaborative storytelling ecosystems

---

# Core Gameplay Loop

Players interact with characters and sounds through a progression cycle:

```
play sounds
→ gain XP
→ unlock slots
→ discover combos
→ collect cards
→ earn credits
→ customize profile
→ return to improve board
```

The system evolves from sandbox interaction into structured progression.

---

# Core Pillars of the Platform

## 1. Characters

Characters are progression objects.

Each character supports:

- XP leveling
- unlockable sound slots
- visual variations
- collectible upgrades
- combo compatibility

Characters begin simple and grow alongside the player.

---

## 2. Sound Slots

Each character starts with limited sound capacity.

Example:

```
1 unlocked slot
5 locked slots
```

Slots unlock through:

- XP progression
- challenges
- combo discovery
- shop upgrades

This creates motivation without requiring complex backend systems early.

---

## 3. Combo Cards

Combo cards are one of the central collectible mechanics.

Each combo card:

- contains 3–6 sounds
- belongs to a themed pack
- has its own visual identity
- can be displayed on profile
- can unlock bonuses

Example packs:

- Tokyo Streets Pack
- Rain Pack
- Alise Cyber Spring Pack
- Gumi Pack
- Neon Metro Pack

These function like collectible playable sound recipes.

---

## 4. Credits Economy

Credits are the platform’s universal progression currency.

Credits can be earned via:

- Ultra Mode challenges
- combo discovery
- character activity
- social interaction
- story participation
- friend engagement bonuses

Credits can be spent on:

- unlocking sound slots
- purchasing combo packs
- upgrading characters
- visual customization

Economy begins local-first and becomes persistent later.

---

## 5. Social Boards

Players interact through each other’s soundboards.

Examples:

- characters appear on friend boards
- friend activity generates passive rewards
- mixes can be ranked
- profiles can be explored

The board continues evolving even when the player is offline.

This creates long-term retention naturally.

---

## 6. Stories System

Stories are the narrative backbone of the platform.

The Stories module includes:

- Tokyo cyber-night introduction story
- character bios
- user-written story branches
- voting systems
- weekly story events

Future expansion:

- illustrated story panels
- sound-enhanced scenes
- animated sequences
- AI-assisted visual generation

Stories transform the platform into a shared creative world.
